# training_records

用于记录训练、减脂、伤病、恢复、营养与补剂相关内容，方便后续持续维护、复盘和排查问题。

---

## 文件说明

- `训练记录.md`：训练主记录文档，保存基础数据、训练过程、身体反馈、饮食补剂、阶段判断和后续追加记录。
- `README.md`：仓库说明与训练记录更新日志索引。

---

## 维护规则

- 每次训练记录有新增、修改或补充时，都同步在 `README.md` 追加一条更新日志。
- `训练记录.md` 保留完整内容，适合查看全貌。
- `README.md` 只记录摘要式变更，方便快速了解最近更新了什么。
