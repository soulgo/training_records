# training_records

用于记录训练、减脂、伤病、恢复、营养与补剂相关内容，方便后续持续维护、复盘和排查问题。

---

## 记录规则

### 1. 体脂秤截图记录规则

后续用户发送华为体脂秤标准截图时，默认按同一格式识别并更新 `训练记录.md`。

优先提取字段：

- 测量时间
- 身体得分
- 体重
- BMI
- 体脂率
- 骨骼肌量
- 内脏脂肪等级
- 基础代谢率
- 水分率
- 蛋白质率
- 骨盐量
- 去脂体重
- 身体年龄

记录方式：

- 若为新的测量记录，则追加到当日记录中。
- 若与已有基础信息一致，则保留当前基础档案，同时新增当天测量快照。
- 若数据出现变化，则在 `训练记录.md` 中记录新数值和测量时间，便于后续观察趋势。

### 2. 运动截图记录规则

后续用户发送运动记录标准截图时，默认按同一格式识别并更新 `训练记录.md`。

优先提取字段：

- 训练类型
- 训练日期与时间
- 时长
- 距离
- 消耗热量
- 均速
- 心率或截图中出现的其他关键指标

当前已识别的常见类型：

- 自由训练
- 户外骑行
- 爬楼

记录方式：

- 按当天时间顺序写入训练记录。
- 同一天的同类训练可额外补充汇总数据。
- 若用户同时提供主观反馈，如累、疼、酸、轻松、状态好，也一并写入当日记录。

### 3. 饮食截图记录规则

后续用户发送饮食记录标准截图时，默认按同一格式识别并更新 `训练记录.md`。

优先提取字段：

- 记录日期
- 餐次（早餐、午餐、晚餐、加餐）
- 每餐建议热量范围
- 每餐实际热量
- 食物名称
- 食物重量或份量
- 单项热量
- 当日总热量（若截图可直接汇总或可计算得到）

记录方式：

- 按日期写入对应当天记录。
- 先记录餐次汇总，再记录餐次明细。
- 若晚餐或某一餐明显超出建议范围，需要单独标记，方便后续分析体脂波动、饱腹感和训练恢复。
- 若用户同时补充主观反馈，如吃撑、很饿、状态差、第二天浮肿，也一并记入当天记录。

### 4. 文字反馈记录规则

后续用户直接用文字补充信息时，也需要同步更新 `训练记录.md`。

常见补充内容包括：

- 疼痛变化
- 恢复情况
- 饮食变化
- 蛋白粉或肌酸使用情况
- 体重、腰围、体脂变化
- 对训练强度的主观感受

记录方式：

- 统一追加到对应日期下。
- 重要异常情况单独写出，方便排查。

## 文件说明

- `训练记录.md`：训练主记录文档，保存基础数据、训练过程、身体反馈、饮食补剂、阶段判断和后续追加记录。
- `README.md`：仓库说明、记录规则与训练记录更新日志索引。

---

## 维护规则

- 每次训练记录有新增、修改或补充时，都同步在 `README.md` 追加一条更新日志。
- `训练记录.md` 保留完整内容，适合查看全貌。
- `README.md` 记录规则和摘要式变更，方便快速了解如何维护以及最近更新了什么。
- 后续优先依据标准截图自动识别更新，减少手动整理成本。
