# Goal Document: Q7-Q10 识别、Provider、慢 SQL 与训练者画像收口

## Go / No-Go

- **Judgment**: Go（Q7/Q8/Q10）；Q9 查询等待 dev 只读连接
- **Reason**: 开放 App 识别、OpenAI-compatible 能力协商和画像实体的产品语义已明确；当前本地环境无任何 dev DB URL，GitHub Secret 只能看到名称不能读取值。

## Target Outcome

Q7-Q10 不再以模糊问题阻塞设计：识别采用“可见事实 + nullable 字段 + 本地校验”，AI Provider 通过能力契约适配 OpenAI 或兼容实现，dev 慢 SQL 使用只读账号实查，训练者画像在现有 PostgreSQL 数据库新增 `core.trainee_profile` 迁移 SQL。

## Goal Definition

- **Type**: technical + data model + operational
- **Boundary**: 更新系统优化文档；新增画像迁移 SQL 与静态合同测试；取得连接后只读查询 dev 慢 SQL。
- **Non-goals**:
  - 不在本轮执行数据库 DDL。
  - 不在没有真实多 App 样本时宣称准确率已提高。
  - 不将 provider 特性写进领域 schema 或 Prompt。
- **Deferred work**:
  - 画像编辑命令/API 和 `/分析` Repository 接入放在后续实现 PR。
  - 真实多 App 准确率报告等未来自然积累脱敏样本后补做。
- **Verification rule**: 文档不再将 Q7/Q8/Q10 列为待澄清；迁移合同测试先 RED 后 GREEN；Q9 输出真实 SQL/plan 证据或明确缺少连接。
- **Evidence source**: 代码/Prompt/SQL 读取、Node test、dev PostgreSQL 只读查询。
- **Pass criteria**: 迁移文件包含约束、权限、seed 和验收 SQL；测试通过；README 与方案一致；凭据不进入 Git。
- **Confidence note**: 结构与契约可自动验证；多 App 识别效果因缺少真图只能标记为待观测，不伪造精度数字。
- **Judgment owner**: 测试 + dev DB 查询证据 + 用户对画像内容的确认。

## Current State

- `AI_PROVIDER=openai-compatible`，模型和 base URL 均为运行时配置，不能以单一模型能力设计。
- `/分析` 目标仍由 `TRAINING_ANALYSIS_GOAL`/硬编码“增肌减腹”提供，数据库没有训练者画像实体。
- 本地 `TRAINING_DB_*` / `DEV_TRAINING_DB_*` 均未配置；GitHub Actions 存在 `DEV_TRAINING_DB_URL` Secret 名称，但值不可读。

## Drift Diagnosis

- **Goal drift**: 不再把“收集齐全 App 截图”当作通用识别开发的前置条件。
- **Phase drift**: 先固定 schema/provider/profile 契约，再做实库慢 SQL 诊断。
- **Validation drift**: “能输出 JSON”不等于“准确”；准确性结论必须依赖真图真值。
- **Compatibility drift**: Provider fallback 只存在 adapter，不在 Prompt 保留多套分支。
- **Cleanup drift**: 不在本轮顺手修复用户正在调整的 SQL 导出/迁移目录。

## Priority Rationale

- 画像会直接影响 `/分析` Prompt 边界，必须先定存储形态。
- Provider 能力不稳定是识别 schema 上线风险，必须由本地 validator 兜底。
- Q9 需要外部凭据，但不阻塞文档与迁移产物。

- **Todos**:

### Phase 2: dev 慢 SQL 实查

- **Purpose**: 回答 Q9，将 9.746 秒持久化从现象定位到具体 SQL/plan。
- **Entry condition**: 安全提供 `DEV_TRAINING_DB_READONLY_URL`（优先）或最小权限临时账号。
- **Phase rules**:
  - 只执行 SELECT、`EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON)` 和允许的统计视图查询。
  - 不在日志/文档/回复中输出 URL、密码或完整主机信息。
- **Todos**:
  - [ ] 核对 schema/index/table row estimate 与 `pg_stat_statements` 可用性
  - [ ] 按 run 时间窗口查询 top SQL，对候选 SQL 执行 EXPLAIN

- **Exit proof**: 至少指认一条慢 SQL，或用实证说明当前数据库无法追溯该历史 run。
- **Stop condition**: 连接非只读且无法保证查询安全，或凭据无效。
