# 重构历史

本目录保存历史重构方案和审查记录。它们是证据，不是当前操作入口。

## 使用规则

- 可以用于追溯"为什么当时这么设计"。
- 不作为当前操作手册。
- 不作为当前代码行为的事实源。
- 新事实不要写进本目录。
- 若归档内容与正式文档冲突，以 [系统核心](../系统核心.md) 和当前代码为准。
