# docs 治理审计修复记录

本文记录 docs 体系治理审计后的修复范围。它是历史记录，不作为当前操作入口。

## 背景

审计结论指出当前 docs 已形成标准化骨架，但尚未达到长期唯一可信源标准。主要问题包括：

- Prompt 文件名错误。
- AI schema 和 adapter 路径错误。
- 归档索引指向不存在的英文目录。
- 正式区残留一次性目标文档。
- 环境变量索引不完整。
- 运维恢复、端到端验收、双通道一致性、AI fallback 演练和字段映射缺少独立文档。

## 已修复方向

- 修正正式文档中的代码路径和 Prompt 文件名。
- 将一次性目标文档移入归档。
- 修正归档 README 和旧版长期文档 README 的路径。
- 补充环境变量索引。
- 补充数据恢复、端到端验收、双通道一致性、AI 主备容灾演练、图片识别字段映射、索引与查询手册。
- 将新增文档接入对应目录 README、文档地图和 AI Agent 任务路由。
