# 系统代码终极重构历史资料

本目录归档 2026-07-11 完成的通用 AI 截图识别与来源无关 ingest 重构。内容用于追溯“重构前是什么、为什么这样设计、如何实施、怎样验收”，不作为当前系统操作手册。

## 阅读顺序

| 顺序 | 文档 | 用途 |
| --- | --- | --- |
| 1 | [当前系统代码分析](01_当前系统代码分析.md) | 重构前代码、数据库、配置和运行链路基线。 |
| 2 | [重构目标](02_重构目标.md) | 总目标、边界、阶段门禁和验收定义。 |
| 3 | [重构方案](03_重构方案.md) | 图片处理、OCR、AI、来源适配、数据库和部署的实施切片。 |
| 4 | [第二阶段目标](04_第二阶段目标.md) | generic ingest 与来源身份收口目标。 |
| 5 | [第二阶段 TDD 记录](05_第二阶段TDD记录.md) | SQL、仓储和清理门禁的红绿重构证据。 |
| 6 | [最终重构报告](06_最终重构报告.md) | 最终架构、修改记录、迁移状态与验证结果。 |

## 使用边界

- 查询当前系统行为：回到 [系统核心逻辑](../../../02_系统核心逻辑/README.md)。
- 查询当前环境配置：回到 [系统配置](../../../01_系统配置/README.md)。
- 执行数据库操作：以当前 `sql/` 文件、代码和当前运维文档为准，不直接照抄历史目标或计划。
- 本目录中的“未完成”“待执行”描述保留当时语境；最终状态优先看本目录的最终报告和当前系统文档。
