# 优先级总览

> 状态：高/中优先级已实现并完成本地测试；低优先级仍未实现
> 本页用于把本目录所有优化项按高/中/低优先级汇总，方便查看、排期和验收勾选。优先级依据是当前代码证据、2026-07-01 dev/main 成功 run 日志，以及对数据安全和运行体验的影响。

## 优先级定义

| 优先级 | 判定标准 | 处理建议 |
| --- | --- | --- |
| 高 | 已在 main/dev 日志或当前代码中复现，影响数据安全、同步时长或核心业务正确性。 | 下一轮重构先做，完成后必须跑线上 run 验收。 |
| 中 | 不会立即阻断当前运行，但会影响识别准确率、权限收敛、维护成本或后续重构风险。 | 高优先级稳定后排期实施，配套测试和文档。 |
| 低 | 主要是体验微调、观测增强或非阻塞清理。 | 跟随相关模块改动顺手处理，不单独打断主线。 |
