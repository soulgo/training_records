## 历史资料分组

| 子目录/文件 | 职责 |
| --- | --- |
| `重构历史/` | v13-v23、核心代码优化、图片 OSS、prompt 改造、Action/Worker 合并等历史方案和审计。 |
| `后续规划_未实现/` | 尚未实现或只作为规划保留的任务。 |
| `旧docs入口_README.md` | 迁移前 docs 入口。 |

## 使用规则

- 查当前配置：读 `../01_系统配置/`。
- 查当前流程：读 `../02_系统核心逻辑/`。
- 查历史原因：读本目录。
- 查未实现建议：读 `后续规划_未实现/`，但不得把其中内容当成当前能力。
