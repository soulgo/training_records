## 建议合并

### 行为事实

```text

+
docs/消息链路/消息链路.md 中的输入命令概述

+

```

合并方式：不移动细节，只把“用户输入会发生什么”收敛到行为手册；原文档保留各自领域细节并链接行为手册。

合并方式：AI 识别体系只保留 schema 顶层和维护流程；字段级映射统一放到数据模型映射文档。

## AI Agent 阅读最短路径

```text
10 分钟系统导览
↓
系统行为手册
↓
消息链路
↓
数据模型
↓
AI 识别体系
↓
运维手册 / 故障排查
```

规则：

1. 默认不读 `docs/归档/**`。
2. 遇到行为问题先读行为手册。
3. 遇到字段问题读图片识别字段映射和 SQL。
4. 遇到 Prompt 问题读 `prompts/_source` 和生成 prompt。
5. 遇到通道问题读消息链路，再读对应 adapter 代码。
