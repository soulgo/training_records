# 版本记录说明

项目版本记录统一维护在根目录 `CHANGELOG.md`。

维护规则：

- 最新正式版本是第一个形如 `## [x.y.z] - YYYY-MM-DD` 的发布条目。
- `## [Unreleased]` 用于记录尚未发布的显著变更。
- 版本按时间倒序排列。
- 版本号遵循 Semantic Versioning。
- 变更分类按需使用 `Added`、`Changed`、`Deprecated`、`Removed`、`Fixed`、`Security`。
- 站点页脚版本号从 `CHANGELOG.md` 最新正式发布条目读取。
- 发布版本时，`CHANGELOG.md`、`package.json` 和 `package-lock.json` 的版本号应保持一致。

文档结构调整、部署说明变化、接口行为变化和维护流程变化，都应在合适版本中记录。
