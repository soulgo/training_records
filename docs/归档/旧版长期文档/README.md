# Legacy Docs

本目录保存本次 docs IA 升级前的长期中文文档。它们曾是维护入口，但现在不再作为当前 SSOT。

## 为什么保留

- 保留迁移前内容，便于追溯细节。
- 避免一次性删除造成信息丢失。
- 后续可以逐篇对照正式文档，确认吸收后再删除。
