# Archive

`归档/` 保存历史方案、迁移前长期文档、审查报告和重构记录。

## 使用规则

- 可以用于追溯“为什么当时这么设计”。
- 不作为当前操作手册。
- 不作为当前代码行为的事实源。
- 新事实不要写进归档。
