# 可删除文档清单

> 审核时间: 2026-06-22

## 结论

本轮不建议继续删除主文档。当前非归档主文档已经承担明确职责，直接删除会损失新人、运维或 AI Agent 的阅读入口。

可删除对象主要来自旧路径或重复迁移残留；归档中的历史文档建议保留审计价值，不作为当前事实源。

| 文档 | 保留原因 |
| --- | --- |

## 建议删除

| 路径 | 建议 | 原因 |
| --- | --- | --- |
| 旧根目录下已迁移的重复文档 | 删除 | 若同名内容已经进入 `docs/归档/旧版长期文档/` 或正式分类，旧路径没有维护价值 |
| 旧 `docs/优化重构/**` 迁移残留 | 删除 | 当前已迁入 `docs/归档/重构历史/**`，继续保留旧路径会制造双重归档 |
| 旧 `docs/训练系统/**` 迁移残留 | 删除 | 当前事实已经拆入行为手册、消息链路、AI 识别体系和数据模型 |

说明：工作树中已存在大量旧路径删除记录，本清单不要求额外删除；只确认这些删除方向符合文档收敛原则。

## 不建议删除但应避免默认读取

| 路径 | 处理 |
| --- | --- |
| `docs/归档/旧版长期文档/**` | 保留审计价值，不作为当前事实 |
| `docs/归档/重构历史/**` | 保留决策过程，不作为当前行为依据 |
| `docs/归档/文档收敛审查报告.md` | 保留本轮审计证据 |
| `docs/归档/重复与冗余分析.md` | 保留本轮收敛判断 |
| `docs/归档/建议合并方案.md` | 保留后续迁移依据 |

## 删除前检查

1. 确认目标内容已迁入正式文档或归档。
2. 运行 docs 链接检查，避免正式入口断链。
3. 确认 `docs/README.md` 不再引用旧路径。
4. 不删除 `归档/` 中仅有审计价值的历史记录，除非另有备份策略。
