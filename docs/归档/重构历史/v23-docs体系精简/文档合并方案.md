## 建议删除

删除前必须确认内容已被目标文档吸收。

| 建议删除 | 原因 |
| --- | --- |
| `docs/总览/系统导览.md` | 合并进根 README 和系统导览 |
| 所有仅作为目录列表的 `README.md` | 目录入口过多，合并后无独立价值 |
| `docs/变更记录/README.md` | 可并入根 README 的维护规则 |
| `docs/开发指南/开发指南.md#项目结构` | 合并进开发指南 |
| `docs/开发指南/开发指南.md#核心模块` | 合并进开发指南 |
| `docs/开发指南/调试方式.md` | 合并进开发指南或故障排查 |
| `docs/运维手册/监控告警.md` | 合并进运维手册 |
| `docs/运维手册/Pending重放.md` | 合并进运维手册 |
| `docs/运维手册/Markdown导入导出.md` | 合并进运维手册 |

## 建议归档

当前主文档中以下内容如果迁移后仍需保留旧文件原貌，应移入 `docs/归档/旧版长期文档/` 或新的 `docs/归档/重构历史/v23-docs体系精简/迁移前快照/`。

| 建议归档 | 原因 |
| --- | --- |
| 被合并后的原专题短文档 | 保留迁移审计价值 |
| 被新主文档替代的目录 README | 保留目录演进证据即可 |
| 与当前事实重复但不再作为入口的旧解释 | 避免主文档重复 |

## 不建议删除的内容

| 内容 | 原因 |
| --- | --- |
| `docs/归档/重构历史/*` | 历史审计证据 |
| `docs/归档/旧版长期文档/*` | 旧 IA 迁移来源，可追溯 |
| ADR 文件 | 架构决策有长期价值，低频维护 |
| 字段映射、环境变量、SQL 查询类资料 | 查表型，高维护价值 |
