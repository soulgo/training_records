# 飞书

## 现象

- 飞书事件进 Worker 后被拒绝。
- 飞书图片无法下载。
- 飞书同步没有写入数据。
- 飞书回执失败。

## 原因

- `FEISHU_ENCRYPT_KEY` 或 `FEISHU_VERIFICATION_TOKEN` 不匹配。
- 飞书签名时间偏移超过 `FEISHU_SIGNATURE_MAX_SKEW_SECONDS`。
- `FEISHU_APP_ID` / `FEISHU_APP_SECRET` 缺失或无权限。
- `FEISHU_ALLOWED_CHAT_IDS` 不包含来源 chat。

## 日志特征

- 飞书 verification token 校验失败。
- `FEISHU_APP_ID and FEISHU_APP_SECRET are required`
- `reason: feishu_api`
- `unauthorized chat`

## 排查步骤

1. 查 Worker 校验：`cloudflare/feishu-sync-dispatch-worker.mjs:146,155,165`。
2. 查飞书 env：`src/app/use-cases/feishu-sync.use-case.mjs:232-249`。
3. 查消息标准化：`src/adapters/feishu/sync-batch-logic.adapter.mjs:5`。
4. 查图片下载：`src/app/use-cases/feishu-sync.use-case.mjs:53-64`。
5. 查回发消息：`src/app/use-cases/feishu-sync.use-case.mjs:65-76`。

## 解决方案

- 修正 Worker secrets。
- 修正 GitHub Actions 中 `FEISHU_*` 或 `DEV_FEISHU_*`。
- 将飞书 chat id 加入白名单。

## 预防措施

- 飞书业务语义通过 `runTelegramSync` 复用，不单独分叉实现。
- 只把 webhook、附件、文件下载和回执差异留在 adapter 层。
