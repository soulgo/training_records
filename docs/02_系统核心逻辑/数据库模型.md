## 权限与迁移边界

当前数据库边界按角色拆分，不再把 DDL 混入日常同步路径：

| 角色 / 连接 | 用途 | 边界 |
| --- | --- | --- |
| `training_migrator` / `TRAINING_DB_MIGRATION_URL` | 显式 migration | 执行 `sql/training_records/migrations/`，写入 `maintenance.schema_migration`；不注入日常同步 workflow。 |
| `training_app` / `TRAINING_DB_URL` | Telegram / 飞书同步和常规写入 | 只做业务 DML；默认不执行 `ALTER TABLE`、`CREATE TABLE`、`CREATE INDEX`。 |
| `training_maintenance` | 显式维护命令 | 用于受控修复、导入和 backfill；仍不替代 migrator 执行 DDL。 |
| `training_readonly` / `TRAINING_DB_READONLY_URL` | 站点构建、快照读取、导出、巡检和一致性检查 | 只读查询；未配置时读取路径才回退 `TRAINING_DB_URL`。 |

`TRAINING_DB_SCHEMA_PREFLIGHT_ENABLED` 默认关闭。只有过渡期显式设置为 `true` 时，运行时代码才会调用 schema preflight；正式 schema 变更应通过 `npm run maintenance:migrate -- --dry-run` 预览、`npm run maintenance:migrate -- --confirm` 执行。

## 幂等

| 对象 | 幂等依据 |
| --- | --- |
| batch | `persistNormalizedBatch` 对完整 batch JSON 计算 SHA-256 `payloadHash`。 |
| activity | `core-row-writer.pg.mjs` 使用 `sourceChannel + date + time + type + detail` 生成 hash/key。 |
| meal | `core-row-writer.pg.mjs` 使用日期和餐次字段生成 key。 |
| sleep | `core-row-writer.pg.mjs` 使用睡眠字段生成 key。 |
| thought | `core.thought` 有 source identity 唯一索引，SQL 位置 `sql/pgsql17.sql:679-681`。 |
